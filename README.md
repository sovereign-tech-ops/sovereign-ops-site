## Publicar no GitHub Pages

1. Crie um repositório público (ex.: `sovereign-ops-site`);
2. Suba **todo o conteúdo desta pasta** `site\` na raiz do repo (index.html na raiz);
3. Repo → **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**;
4. Em ~1 minuto o site fica em: `https://SEUUSUARIO.github.io/sovereign-ops-site/`.
